🚀 Projeto ASP.NET, SQL Server – Empréstimos de Equipamentos 💻📦

Este projeto foi desenvolvido com fins educacionais e tem como objetivo a criação de uma aplicação web utilizando ASP.NET Core, SQL Server e Entity Framework para gerenciamento de empréstimos de equipamentos tecnológicos, como notebooks, projetores, tablets e outros. 🛠️🔌

🔧 Tecnologias Utilizadas:
- ASP.NET Core
- SQL Server
- Entity Framework Core
- Razor Pages / MVC
- Bootstrap

📋 Funcionalidades:
✅ Cadastro de novos empréstimos
✅ Edição e visualização de empréstimos registrados
✅ Exclusão de registros
✅ Interface amigável e responsiva

🧠 Objetivos do Projeto:
- Praticar conceitos de desenvolvimento backend com ASP.NET Core
- Aprender e aplicar operações CRUD com Entity Framework
- Desenvolver habilidades com banco de dados relacional (SQL Server)
- Criar uma interface funcional e intuitiva

📈 Estrutura do Projeto:
- Camada de dados com Entity Framework (Modelos e DbContext)
- Controllers com lógica de negócio
- Views para interação com o usuário
- Migrations para versionamento do banco de dados
